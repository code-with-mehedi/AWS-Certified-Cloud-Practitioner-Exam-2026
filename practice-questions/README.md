# 📝 CLF-C02 Practice Questions

[⬅️ Back to the study guide](../README.md)

Test yourself after studying each topic: **5 exam-style questions for each of the 18 study guide topics (90 questions in total)**. Most questions have one correct answer, and some ask you to choose two or three, like the real AWS Certified Cloud Practitioner (CLF-C02) exam.

> [!NOTE]
> **How it works on GitHub.** GitHub cannot run scripts or form controls inside Markdown, so every answer option is a collapsible block. **Click an option to reveal whether it is ✅ right or ❌ wrong, and why.**
> - ◯ **Round marker:** pick **one** answer (like a radio button).
> - ☐ **Square marker:** pick **all** the answers the question asks for (like checkboxes). Click each option you think is correct.
