### Question 1

A company wants to turn written text into lifelike speech for a voice assistant. Which service should it use?

*◯ Choose ONE.*

<details><summary>◯ <b>A.</b> Amazon Transcribe</summary>

❌ **Incorrect.** Transcribe does the reverse: it converts speech to text.

</details>

<details><summary>◯ <b>B.</b> Amazon Translate</summary>

❌ **Incorrect.** Translate converts text from one language to another.

</details>

<details><summary>◯ <b>C.</b> Amazon Lex</summary>

❌ **Incorrect.** Lex builds conversational chatbots using voice and text.

</details>

<details><summary>◯ <b>D.</b> Amazon Polly</summary>

✅ **Correct.** Polly is a text-to-speech service.

</details>

### Question 2

A company wants to build generative AI applications using foundation models from several providers through a single serverless API. Which service should it use?

*◯ Choose ONE.*

<details><summary>◯ <b>A.</b> Amazon SageMaker AI</summary>

❌ **Incorrect.** SageMaker AI (formerly Amazon SageMaker) is a platform to build, train, and deploy your own machine learning models.

</details>

<details><summary>◯ <b>B.</b> Amazon Rekognition</summary>

❌ **Incorrect.** Rekognition analyzes images and videos, for example to find objects, faces, and text.

</details>

<details><summary>◯ <b>C.</b> Amazon Comprehend</summary>

❌ **Incorrect.** Comprehend is a natural language processing service for tasks such as sentiment analysis and entity extraction.

</details>

<details><summary>◯ <b>D.</b> Amazon Bedrock</summary>

✅ **Correct.** Bedrock provides API access to foundation models from Amazon and other AI companies without managing infrastructure.

</details>

### Question 3

Which TWO AWS-designed chips are purpose-built for deep learning workloads?

*☐ Choose TWO.*

<details><summary>☐ <b>A.</b> AWS Graviton</summary>

❌ **Incorrect.** Graviton is an AWS-designed ARM-based CPU for general-purpose workloads, not a deep learning accelerator.

</details>

<details><summary>☐ <b>B.</b> Intel Xeon Scalable processors</summary>

❌ **Incorrect.** These are CPUs designed by Intel, not by AWS.

</details>

<details><summary>☐ <b>C.</b> AWS Trainium</summary>

✅ **Correct.** Trainium is designed for deep learning model training.

</details>

<details><summary>☐ <b>D.</b> NVIDIA GPUs</summary>

❌ **Incorrect.** These are designed by NVIDIA, not by AWS.

</details>

<details><summary>☐ <b>E.</b> AWS Inferentia</summary>

✅ **Correct.** Inferentia is designed for deep learning inference, delivering predictions at low cost.

</details>

### Question 4

A company needs to extract printed text, handwriting, forms, and tables from scanned documents. Which service should it use?

*◯ Choose ONE.*

<details><summary>◯ <b>A.</b> Amazon Textract</summary>

✅ **Correct.** Textract extracts text, handwriting, forms, and tables from documents.

</details>

<details><summary>◯ <b>B.</b> Amazon Rekognition</summary>

❌ **Incorrect.** Rekognition analyzes images and videos for objects, faces, and text in scenes, but it is not built to extract forms and tables from documents.

</details>

<details><summary>◯ <b>C.</b> Amazon Comprehend</summary>

❌ **Incorrect.** Comprehend analyzes the meaning of text, such as sentiment, entities, and key phrases. It does not extract forms and tables from documents.

</details>

<details><summary>◯ <b>D.</b> Amazon Kendra</summary>

❌ **Incorrect.** Kendra is an intelligent enterprise search service.

</details>
